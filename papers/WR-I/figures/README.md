# WR-I Figures

This directory is reserved for publication figures that carry scientific content.

Do not add decorative figures merely to increase visual density. Candidate figures should correspond to explicit manuscript objects, for example:

1. protocol refinement and quotient maps;
2. gauge orbit versus response fibre;
3. finite-resolution separation on a compact admissible domain;
4. WR-I -> WR-II handoff diagram.

Every figure must have a source file or reproducible generation procedure before release.
