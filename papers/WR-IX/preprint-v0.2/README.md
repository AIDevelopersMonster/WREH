## Reproduce

Python 3 with numpy, scipy, matplotlib, sympy and pypdf; XeLaTeX with fontspec, polyglossia, Nimbus fonts and Russian hyphenation; Node.js with Playwright and a Chromium-compatible executable.

```bash
python3 scripts/reproduce.py
python3 scripts/audit_checks.py
python3 scripts/figure.py
python3 scripts/build.py --build-dir /tmp/wreh-wrix-build
node scripts/verify_demo.cjs
python3 scripts/verify_source.py
python3 scripts/package.py --output-dir /tmp/wreh-wrix-package
```

`WREH_CHROME_PATH` selects a compatible Chromium/headless-shell binary; `WREH_SCREENSHOT_DIR` enables screenshots. Build intermediates stay outside the package. `requirements.txt` records Python versions used; `package.json` records the browser-check dependency. Reports distinguish completed numerical/boundary/browser checks from general analytic proofs and external peer review. Rebuilding reports resets visual-review fields to PENDING until new renders are inspected.

Source context is pinned in `SOURCE_PROVENANCE.json`. `SOURCE_MAP.md` records which earlier sources were actually inspected and what remains unverified. No VIII frozen scientific source is changed; its DOI/publication status is updated only in active metadata and a separate post-publication report.

Research content/figures CC BY 4.0; scripts and executable HTML MIT. The archive is generated by `scripts/package.py` and is not stored in Git. No IX DOI is invented; prepared Zenodo metadata is a deposit draft only.
