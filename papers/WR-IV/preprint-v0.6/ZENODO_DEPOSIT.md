## Deposit procedure

Create a new upload, attach the prepared files, fill the fields and review the description. If a DOI is reserved before publication, insert that actual DOI into the citation metadata and rebuild/repackage before uploading replacement files. Alternatively, leave the manuscripts without a DOI stamp and use the DOI assigned on publication when citing the record. The existing three upstream DOIs identify other papers and must not be used as the WR-IV DOI.

Before publishing, confirm the creator, files, licence and date in Zenodo's preview. Community submission can be moderated independently of publication. Publishing is a separate action from creating this package and has not been performed here.

Official references checked 8 October 2026: [create a new upload](https://help.zenodo.org/docs/deposit/create-new-upload/) and [deposition API metadata](https://developers.zenodo.org/).
