Persistent operational equivalence

If the physically admissible protocol family is restricted to Pa, Pb and Ph, then the gauge label can never be identified. More generally, a hidden physical degree of freedom would define an epistemic horizon if no admissible protocol can separate its realizations.

Why Pg is shown

Turning on Pg demonstrates a category error: a protocol that reads a gauge label can artificially make every representative look physically distinguishable. WREH therefore requires the admissible protocol class to be part of the model definition.
